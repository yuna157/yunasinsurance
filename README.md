# YUNA'S INSURANCE – 나의 보험 상담소

## 처음 사용하기

1. `yunas_insurance_app.zip`을 압축 해제합니다.
2. Windows에 Python 3가 설치돼 있으면 `start-local.cmd`를 더블클릭하고 Edge 또는 Chrome을 사용합니다. 콘솔 창을 닫으면 로컬 앱이 종료됩니다. macOS·Linux에서는 앱 폴더에서 `python3 -m http.server 8765 --bind 127.0.0.1`을 실행하고 `http://localhost:8765/`를 엽니다. 앱을 쓰는 동안 같은 주소와 포트를 사용하세요.
3. HOME의 **자료 가져오기**에서 `yunas_insurance_private_backup.zip`을 압축 해제 없이 선택합니다. 참고 PDF 23개와 구조화된 25개 자료 이력, 정상 계약 10건이 표시됩니다. 별도의 `yunas_insurance_checkpoint.json`은 PDF 없이 계약과 담보 정보만 복원할 때 사용합니다.
4. HOME에서 진료나 사고 내용을 입력하고 **한도·제외사항·청구서류·근거**를 펼쳐 보세요. 근거 버튼을 누르면 등록된 원본의 해당 페이지가 열립니다.

## GitHub Pages

1. 앱 ZIP을 압축 해제한 다음 `index.html`, `vendor` 등 **앱 폴더 안의 배포 파일**을 저장소에 업로드합니다.
2. GitHub에서 **Settings → Pages → Build and deployment**의 **Deploy from a branch**를 선택하고 `main` 및 `/ (root)`를 지정합니다.
3. 생성된 HTTPS 주소를 연 뒤 각 기기에서 개인 자료 ZIP을 직접 가져옵니다. 공개 저장소에는 개인 자료 ZIP, 보험 데이터 JSON, 증권·약관 원본, 청구 기록을 업로드하지 마세요.
4. Android 또는 데스크톱 브라우저에서는 앱의 **홈 화면에 추가** 또는 브라우저의 설치 메뉴를 사용하세요. iPhone은 Safari에서 **공유 → 홈 화면에 추가**를 선택합니다. 설치 안내가 표시되지 않으면 브라우저 메뉴를 사용하세요.
5. 첫 온라인 접속에서 오프라인용 앱 파일을 받아요. 초기 로딩이 끝나면 검색, PDF, 백업을 같은 사이트 주소에서 오프라인으로 사용할 수 있습니다.

## 개인 자료와 백업

- 보험 데이터와 파일은 현재 브라우저와 사이트 주소에 귀속됩니다. 기기나 브라우저를 바꿀 때는 이전 환경의 **SETTINGS → PDF 포함 백업**에서 만든 최신 ZIP을 새 환경에서 복원하세요. 복원은 기존 계약과 청구 기록을 가져온 파일의 내용으로 교체합니다.
- JSON 내보내기는 구조화된 계약·담보·청구 기록과 PDF 목록을 담습니다. PDF를 같이 옮기려면 ZIP을 사용하세요. ZIP 파일에는 개인정보가 담긴 원본이 포함되고 ZIP 자체는 암호화되어 있지 않으므로 개인 보관용으로 관리하세요.
- PDF 본문 검색은 텍스트를 추출할 수 있는 페이지에서 작동합니다. 이미지로만 된 스캔본은 열람할 수 있으며, 본문 검색에는 별도 OCR로 만든 텍스트형 PDF가 필요합니다.
- 단체보험 3건 및 KB 자동차보험·하나 저축보험은 계약 유지를 확인했으나 담보 상세를 받으면 추가 확인이 필요합니다. M-Drive2007은 해당 종형 전체 약관, M-Drive2004는 스쿨존 추가 보장 배서가 남아 있습니다.
- 지급 조건은 해당 사고일에 적용된 증권·약관 및 보험사 심사에 따릅니다. 앱의 금액은 가입금액 또는 확인된 산정 기준으로 표시합니다.
